# Ashutosh Mishra — Portfolio

A responsive, single-page portfolio ready for GitHub Pages. It uses plain HTML, CSS, and JavaScript; no build step or dependencies are needed.

## Preview

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository. For a personal site, name it `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root and commit them.
3. For a project repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit the Pages URL shown in the repository settings.

## Personalize

Update the content in `index.html` and styles in `styles.css`. Replace the email address if needed. Google Fonts requires an internet connection; system fallbacks are included.

The project descriptions are framed as concepts/simulations, matching the supplied resume. No real LinkedIn or GitHub profile links were provided.
